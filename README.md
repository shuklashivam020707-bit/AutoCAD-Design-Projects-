# Flanged Bearing Housing Assembly

A standardized 2D engineering drawing of a Flanged Bearing Housing created in AutoCAD 2027 following ISO/ASME Y14.5 drafting standards.

## 🛠️ Technical Specifications
* **Bore Diameter:** Ø50 mm
* **Pitch Circle Diameter (PCD):** Ø130 mm (4 x M10 mounting bolt pattern)
* **Flange Dimensions:** 140 mm width, 150 mm base
* **Wall Thickness / Cover Plate:** 10 mm
* **Material / Process:** Cast Iron / Machined Bore & Mounting Flange

## 📐 Drafting & CAD Features
* **Projections:** Third-Angle Projection (Front Elevation & Side Elevation Views).
* **Centerlines & Hidden Lines:** Applied correct layer linetypes (`CENTER` for PCD/axes and `HIDDEN` for internal bores).
* **Break Lines:** Utilized spline (`SPL`) S-curves for conventional shaft representations.
* **Monochrome Export:** Processed using `monochrome.ctb` plot style for high-resolution vector PDF printing.
